# Gerador de QR Code

Aplicativo desenvolvido em Flutter para gerar QR Codes a partir de textos ou links informados pelo usuário.

## Funcionalidades

- Entrada de texto ou link
- Geração de QR Code
- Exibição do QR Code na tela
- Validação através de teste automatizado

## Tecnologias utilizadas

- Flutter
- Dart
- qr_flutter
- Git
- GitHub

## Dependência principal

O projeto utiliza a biblioteca:

qr_flutter: ^4.1.0

## Como executar

Instale as dependências:

flutter pub get

Execute o aplicativo:

flutter run

## Testes

Para executar os testes automatizados:

flutter test
